# Claude entrypoint

Read [AGENTS.md](AGENTS.md), [CONVENTIONS.md](CONVENTIONS.md), and [docs/tracking/context.md](docs/tracking/context.md). They define the same task, safety, publication, and cost policy used by every assistant.

Use `agent=claude` in tracking rows. The coordinating agent may publish authorized work through guarded `make git` and PRs; delegated agents return evidence to their parent. Do not change protected branches directly, add unlisted model fallbacks, or mistake fixture tests for live provider evidence.

Use short progress updates. Complete authorized independent work until done or blocked by a concrete dependency. Never ask repeatedly for approval already given in the session.
